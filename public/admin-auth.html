⚠️ Supabase में Phone provider चालू नहीं है — toggle ON करने पर भी login/register पेज पर Mobile OTP तब तक नहीं दिखेगा। नीचे Setup देखें।

🛠 Setup (Supabase Dashboard → Authentication)

  1. Custom SMTP (ज़रूरी): Settings → SMTP → Resend: host smtp.resend.com, port 465, user resend, password = Resend API key, sender = noreply@jaigahoi.in। (Supabase का built-in email बहुत सीमित है — घंटे में कुछ ही mail, OTP signup वहीं अटकेगा।)
  2. Email Templates: "Confirm signup" और "Magic Link" दोनों में {{ .Token }} जोड़ें, वरना mail में code नहीं आएगा — supabase/auth-email-templates.md देखें।
  3. Password length: Providers → Email → Minimum password length = 8।
  4. Redirect URLs: URL Configuration → Site URL https://jaigahoi.in; Redirect URLs में /auth-callback.html और /forgot-password.html जोड़ें।
  5. Google: Providers → Google ON (Client ID/Secret, redirect: Supabase callback URL)।
  6. Mobile OTP (बाद में): Providers → Phone ON + SMS provider (Twilio / MessageBird / Vonage / Textlocal) का account जोड़ें; भारत में DLT registration ज़रूरी है। फिर यहाँ toggle ON करें।
  7. Rate limits: Authentication → Rate Limits में OTP/email की सीमा देखें।
